Unit-wise Overview

Select a unit to view its topics.

Unit 1 – Internet and Web Fundamentals

History of the Internet, World Wide Web, HTML, HTTP, SMTP, POP3, MIME, IMAP, Domain Name Server, Web Browsers and Web Servers.

Unit 2 – HTML, CSS, JavaScript and XML

Lists, Tables, Images, Forms, Frames, Dynamic HTML, JavaScript, CSS, XML Schemas, Object Models, DOM and SAX.

Unit 3 – Web Services and AJAX

Web Services, UDDI, SOAP, WSDL, Web Services Architecture, Development, Deployment, AJAX and CORBA.

Unit 4 – Web 2.0 and Web 3.0

Blogs, Wikis, Social Networking, AJAX, RSS, Ruby on Rails, Open APIs, Semantic Web, Widgets, Mashups, RDF, Search Engines, Recommender Systems, Blockchain and Edge Computing.

Unit 5 – Web 4.0 and Emerging Technologies

AI-Powered Web, Personalized Content, Decentralized Web, Blockchain, IoT, AR, VR, Smart Web, Adaptive Interfaces, Web Automation and 5G.
